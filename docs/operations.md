# Эксплуатация

## Смена ИИ-модели

Название модели не зашито в код — правится в `.env`:

```
AI_MODEL_PRIMARY=gemini-3.5-flash
AI_MODEL_FALLBACK=gemini-2.5-flash
```

Затем `docker compose up -d bot worker`. Перед сменой сверьте актуальность
модели с официальным графиком поддержки Google (preview-модели в production
не используются). Цены на токены для учёта расходов — в `app/ai/budget.py`
(`PRICES`).

## Смена API-ключей

- `BOT_TOKEN`, `GEMINI_API_KEY`, `POSTGRES_PASSWORD` — в `.env`, затем
  `docker compose up -d`. Реальные ключи в Git не попадают (`.gitignore`).

## Лимиты расходов ИИ

`AI_DAILY_BUDGET_USD`, `AI_MONTHLY_BUDGET_USD`, `AI_BUDGET_ACTION=block|fallback`.
На 80% и 100% лимита администраторы получают уведомление в Telegram.

## Возвраты

Карточка заказа в админке → «Возврат Stars» (использует `refundStarPayment`
по сохранённому `telegram_payment_charge_id`). Повторный возврат блокируется
статусом платежа.

## Ошибки генерации

3 попытки с растущей задержкой (30с/2м/10м), после — уведомление админам.
Из карточки заказа: повторить генерацию, отправить результат вручную,
отменить задание, вернуть оплату.

## Передача проекта другому специалисту

Проект не содержит привязок к разработчику: стандартные Python/Docker/Alembic.
Передаются: репозиторий с историей, `.env` (заполненный Заказчиком),
доступы к серверу/домену/БД/Gemini, учётка админ-панели
(`scripts/create_admin.py`). Смена всех ключей после передачи обязательна.

## Права администратора панели

Создание/смена пароля: `docker compose run --rm bot python -m scripts.create_admin <login> <pass> [tg_id]`.
Вход блокируется на 15 минут после 5 неверных паролей; входы пишутся в
журнал действий (`admin_audit_log`).
