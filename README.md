# Taro Bot — Telegram-бот раскладов Таро и натальных карт

Телеграм-бот с оплатой в Telegram Stars, интерпретациями через OpenAI API,
расчётом натальных карт (Swiss Ephemeris) и веб-админкой.

## Состав

| Компонент | Технология | Каталог |
|---|---|---|
| Telegram-бот | aiogram 3 (long polling) | `app/bot/` |
| Очередь генерации | arq + Redis | `app/worker/` |
| Админ-панель | FastAPI + Jinja2 | `app/admin/` |
| БД | PostgreSQL 16 + SQLAlchemy 2 + Alembic | `app/db/`, `alembic/` |
| Модуль Таро | серверный ГСЧ (`secrets`) | `app/tarot/` |
| Натальная карта | Swiss Ephemeris + IANA tzdata | `app/natal/` |
| ИИ | OpenAI Responses API (модель в настройках) | `app/ai/` |
| Бэкапы | pg_dump ежедневно, контейнер `backup` | `scripts/` |

## Быстрый старт

```bash
cp .env.example .env        # заполнить BOT_TOKEN, пароли, OPENAI_API_KEY
docker compose up -d --build
# Миграции и первичное заполнение карт/услуг выполняются автоматически.
docker compose run --rm bot python -m scripts.create_admin admin 'ПАРОЛЬ' 111111111
```

Админ-панель напрямую: `http://<IP-сервера>:8000/`. Также доступен вариант через
Nginx по `https://<домен>/` при настроенных сертификатах в `nginx/certs/`.

## Важные замечания

- **Swiss Ephemeris**: `pyswisseph` по умолчанию не устанавливается. Для закрытого
  коммерческого проекта требуется Swiss Ephemeris Professional License (приобретается
  Заказчиком), иначе действует AGPL. Включение: `INSTALL_SWISSEPH=true` в `.env`, затем
  `docker compose up -d --build`. Пока библиотека не установлена, раздел «Натальная
  карта» в боте показывается как временно недоступный и оплата не принимается.
- **OpenAI API**: ключ и платёжный профиль принадлежат Заказчику; расходы
  оплачиваются отдельно. Модель задаётся в `.env` (`AI_MODEL_PRIMARY`).
- **Telegram Stars**: цифровые услуги внутри Telegram оплачиваются только в XTR;
  возвраты — через `refundStarPayment` из карточки заказа в админке.
- **Тестовая оплата**: при `TEST_PAYMENT_ENABLED=true` администраторы из
  `ADMIN_TG_IDS` могут запускать оплаченный сценарий без списания Stars.
- **Юридические документы** (условия использования, политика конфиденциальности,
  согласие на обработку персональных данных) хранятся вне бота, например на Google Диске.
  Ссылки задаются в админке, раздел «Тексты бота» → «Документы»: `terms_url`,
  `privacy_url`, `pd_consent_url`. Они подставляются в текст под приветствием и в ответы
  команд `/terms`, `/privacy`, `/pd_consent`. Пока ссылка пустая, показывается текст-заглушка.
- **Тексты бота**: все сообщения, кнопки и уведомления бота редактируются в админке,
  раздел «Тексты бота» (список и тексты по умолчанию — `app/services/texts.py`).
  Оформление (жирный, курсив, подчёркнутый, зачёркнутый, спойлер, ссылки) задаётся
  кнопками над текстом; разметка проверяется при сохранении, чтобы Telegram её принял.
  В базе хранятся только изменённые тексты, «↺ Стандартный» возвращает исходный.
- **Приветствие**: картинка `app/assets/welcome.jpeg`, текст `welcome_text`, под ним
  `consent_text` и кнопка «НАЧАТЬ». При замене файла картинки она перезагрузится сама.
- **Раздел «Натальная карта»**: кнопками выводятся все активные услуги типа `natal`.
  Маркеры в поле «Обязательные поля»: `partner` — сбор данных второго человека
  (совместимость), `transits` — расчёт транзитов на 12 месяцев (прогноз).
